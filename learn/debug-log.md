# Debug log

## 2026-10-13 — TypeScript не видит import './App.css'

### Ошибка
Cannot find module or its corresponding type declarations.

### Причина
Файл декларации типов был создан не в той папке
или TypeScript-конфиг не включал его в проект.

### Как нашёл
1. Проверил путь к App.css.
2. Проверил название файла.
3. Открыл tsconfig.app.json.
4. Переместил globals.d.ts в src.
5. Перезапустил TypeScript Server.

### Правило на будущее
Файлы .d.ts должны быть включены в область tsconfig;
после изменения конфигурации нужно перезапускать TS Server.

## 2026-10-13 — Блокировка запуска скриптов npm в PowerShell

### Ошибка

`PSSecurityException`: Невозможно загрузить файл `C:\Program Files\nodejs\npm.ps1`, так как выполнение сценариев отключено в этой системе.

### Причина

Политика безопасности PowerShell по умолчанию запрещает выполнение локальных скриптов и пакетных файлов (`.ps1`), которые запускаются при вызове команд Node.js/npm.

### Как нашёл

1. Запустил проект в терминале VS Code через команду `npm run dev`.

2. Проанализировал текст ошибки безопасности и ссылку на документацию Microsoft в консоли.


### Правило на будущее

При работе с Node.js в PowerShell на новой машине нужно один раз настроить политику выполнения скриптов для текущего пользователя (`Set-ExecutionPolicy RemoteSigned -Scope CurrentUser`).
